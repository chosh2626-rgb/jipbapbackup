🌐 150명 이상 대회 준비하기

퀴즈 프로그램을 인터넷 서버에 올려 두면, 진행자 컴퓨터를 켜 두지 않아도
몇백 명이 휴대폰 데이터·와이파이 어디서나 들어올 수 있어요.

▲ Vercel에 올려서 쓰기

GitHub에 있는 퀴즈를 Vercel(무료)에 연결하면
진행자 컴퓨터를 켜 두지 않아도 휴대폰 데이터·와이파이 어디서나 들어올 수 있어요.

준비물: 이미 만들어 둔 GitHub 보관함 jipbapbackup (퀴즈 파일이 들어 있는 곳)
처음 한 번만 15분 정도 걸려요. 사이트 화면은 영어예요. 누를 버튼 이름을 그대로 적어 두었어요. 사이트가 바뀌어 글자가 조금 다를 수 있어요.
한눈에 보기 — 이 순서대로 4단계만 하면 돼요.
1Vercel 가입 → 2퀴즈 올리기(비밀번호 정하기) → 3저장소 연결 → 4다시 올리기

1단계. Vercel 가입하기

vercel.com 접속 → Sign Up → Hobby(무료) 선택 → 이름 입력 → Continue with GitHub → GitHub 로그인 후 Authorize(허락).
카드 번호는 넣지 않아도 돼요.

2단계. 퀴즈 올리기 (진행자 비밀번호 정하기)

1보관함 고르기

첫 화면에서 Add New… → Project
목록에서 jipbapbackup 옆의 Import를 눌러요.
목록에 없으면 Install(또는 Adjust GitHub App Permissions)를 눌러 jipbapbackup을 골라 주세요.

2진행자 비밀번호 정하기 ← 꼭 해야 해요!

설정 화면에서 Environment Variables를 눌러 펼치고 아래처럼 써요.
• Key(이름): HOST_PASSWORD
• Value(값): 원하는 비밀번호 (예: eunhye2026)
→ Add
다른 칸(Framework, Root Directory 등)은 건드리지 않아요.

3올리기

Deploy 클릭 → 1분 정도 기다리면 축하 화면(🎉 Congratulations)이 나와요.
Continue to Dashboard를 눌러요.

3단계. 저장소 연결하기 (점수·참가자 기억하는 곳)

Vercel은 요청이 올 때만 잠깐 켜지는 방식이라, 참가자·점수를 적어 둘 무료 저장소(Upstash Redis)가 필요해요.

1프로젝트 화면 위쪽 메뉴에서 Storage

2Create Database (또는 Marketplace에서) → Upstash(Upstash for Redis) 또는 Redis 중 하나 선택 → Continue

둘 다 쓸 수 있어요. 퀴즈가 연결된 저장소를 자동으로 찾아요.

3설정

• 지역(Primary Region): Seoul이 있으면 Seoul, 없으면 Tokyo (ap-northeast)
• 요금제(Plan): Free
• 이름: 아무거나 (예: quiz-db) → Create

4프로젝트에 연결

Connect Project가 나오면 jipbapbackup를 고르고 → Connect.
(Development, Preview, Production 세 칸 모두 체크된 그대로 두세요.)

4단계. 다시 올리기 (Redeploy)

저장소를 연결한 뒤에는 한 번 다시 올려야 적용돼요.
위쪽 메뉴 Deployments → 맨 위 줄 오른쪽 ⋯ → Redeploy → 다시 Redeploy.
1분 뒤 Ready가 되면 끝!

🎉 대회 날 쓰는 법

1진행자 화면 열기

Vercel 프로젝트 화면의 Domains에 있는 주소(예: jipbapbackup-abc.vercel.app) 뒤에 /host를 붙여 열어요.
예) https://jipbapbackup-abc.vercel.app/host
→ 2단계에서 정한 비밀번호 입력 → QR코드 화면이 나와요. 빔프로젝터에 띄우세요.

2참가자

휴대폰 카메라로 QR코드를 찍어요. 데이터(LTE·5G)든 와이파이든 상관없어요.
이름 → 나이대 → 입장하기

3진행

🎲 무작위 문제 내기 → 참가자가 답을 누르고 [제출하기] → 30초가 지나거나 모두 내면 정답 공개 → 🏆 순위
✅ 좋은 점
• 진행자 컴퓨터·검은 창을 켜 둘 필요가 없어요. 노트북·태블릿 어디서든 /host 주소만 열면 돼요.
• 📝 문제 관리에서 고친 문제가 저장소에 저장돼서 사라지지 않아요.
• 주소(QR)가 바뀌지 않아서 QR코드를 미리 인쇄해 두어도 돼요.
⚠️ 알아 둘 점
• 화면이 실시간 연결 대신 1초마다 확인하는 방식이라, 제출 목록이 0.5~1초 늦게 뜰 수 있어요. 걸린 시간은 서버에서 재므로 순위는 공정해요.
• 무료 저장소는 한 달 사용량 한도가 있어요. 100명이 한 시간 하는 대회 몇 번은 충분해요.
• 대회 시작 전에 ♻️ 초기화 → 참가자까지 모두 지우기로 연습 기록을 지워 주세요.
• GitHub의 퀴즈 파일을 고치면 Vercel에 1~2분 뒤 자동으로 반영돼요.
